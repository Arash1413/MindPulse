🧠 MindPulse

 یک پروژه با محوریت هوش مصنوعی و سلامت روان است که با هدف افزایش آگاهی کاربران نسبت به وضعیت روانی، بهزیستی فردی و راهبردهای مقابله با استرس طراحی شده است.

این پروژه با استفاده از فناوری‌های توسعه وب، بستری برای ارائه قابلیت‌های مرتبط با ارزیابی و شناخت بهتر وضعیت روانی کاربران فراهم می‌کند.

🧠 تمرکز بر سلامت روان و بهزیستی فردی

📊 بررسی شاخص‌های مرتبط با وضعیت روانی

💪 توجه به تاب‌آوری و توانایی مقابله با شرایط دشوار

🔍 استفاده از چارچوب Brief COPE برای بررسی راهبردهای مقابله‌ای

⚙️ استفاده از Django برای توسعه بخش سمت سرور
